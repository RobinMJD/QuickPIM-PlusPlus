Changes since [v2.18.9](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.9).

## Changelog

### Release safety

- Blocks every publication job unless the tagged commit is on `main` and the exact same commit already has a completed, successful CI run.
- Keeps GitHub release creation, Chrome Web Store submission, and Microsoft Edge Add-ons submission downstream of the full package verification job.
- Fails closed for missing, failed, cancelled, skipped, timed-out, or otherwise non-successful CI results.

### Store publication

- Adds Chrome Web Store status checks and replacement of an older active review or staged submission before uploading the new version.
- Makes same-version Chrome publication retries idempotent when that version is already pending review.
- Documents the Microsoft Edge API boundary: Edge review cancellation remains a Partner Center action because the publishing API has no cancellation endpoint.

## Validation

- Adds focused tests for the exact-commit CI gate and Chrome submission replacement behavior.
- Revalidates version synchronization, Edge compatibility, type checking, 579 unit tests, dependency audit, production build, browser visual checks, and Store ZIP integrity.
