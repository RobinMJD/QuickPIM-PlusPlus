Changes since [v2.18.10](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.10).

## Changelog

### Extension lifecycle and approval

- Preserve Microsoft approval-required extension states instead of reporting them as already scheduled.
- Prevent duplicate extension requests while approval or scheduling is already in progress.
- Show approval-aware wording in Activity and desktop notifications, including approved, denied, failed, and canceled outcomes.
- Keep expiry reminders informational while an extension is awaiting approval or already scheduled.
- Reconcile active-role rows at the Microsoft end time and refresh only the affected role source.
- Fix duplicate Microsoft Edge notification actions and clear the original reminder after an action.
- Release stale extension locks when Microsoft never exposes an accepted continuation, while keeping real pending approvals protected.
