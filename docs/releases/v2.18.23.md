Changes since [v2.18.22](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.22).

## Changelog

- Confirm approved Entra and Azure activations when the assignment is visible and other Microsoft reads fail. Keep approved status checks running in the background across popup closure.
- Keep deactivation and extension history tied to the correct assignment and request. An earlier deactivation or denied extension can no longer clear a newer request's state.
- Preserve the pending browser-sync deletion through a reset or restart. Retry the deletion before resuming sync so old settings cannot return.
- Use available portal storage when another storage area is inaccessible. Handle malformed Microsoft responses without losing valid role data.
- Build the same Store package across time zones and prevent canceled releases from starting Store submissions.

## Validation

- 694 unit tests and 66 browser tests cover approval reconciliation, popup and browser restart, concurrent requests, interrupted reset, and malformed Microsoft responses.
- Type checking, build, Edge compatibility and sideload smoke testing, version synchronization, dependency audit, and package verification passed.
- Microsoft request tests use synthetic accounts and offline API responses.
