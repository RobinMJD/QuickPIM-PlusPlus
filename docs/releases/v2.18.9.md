## Changelog

### Access recovery consistency

- Reloads the persisted capability cache after Settings hydration and pending autosaves complete.
- Prevents **Open missing portal pages** from opening unnecessary Microsoft tabs when a valid token and fresh capability cache are already available.
- Makes **Recheck now** evaluate the same current cache snapshot instead of a stale render-time value.

- Type checking, production build, Microsoft Edge compatibility and sideload smoke tests passed.
- All 8 Playwright popup and Settings flows passed.
