Changes since [v2.18.20](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.20).

## Changelog

- Allow disabling an active assignment without filling fields required only for activation. Preserve the actual activation start time when scheduling a five-minute disable retry.
- Verify that the original activation is still live before requesting an extension, including after browser restart. Keep missing Azure activation policies unresolved, reject stale-account policy lookups, and distinguish failed validation from uncertain writes.
- Apply API deadlines through response-body reads and cancellation, so stalled responses cannot leave requests waiting indefinitely.
- Preserve concurrent settings changes, active request tracking during history clearing or restore, and new drafts with different account, duration, reason, or ticket details. Protect saved drafts when storage cannot be read.
- Reconstruct temporary Microsoft recovery-tab ownership after browser restart before using saved tab IDs. Display international account names correctly.
- Reduce idle progress polling, resume frequent updates when new work arrives, expire terminal disable notices automatically, and retain their history in Settings.
- Improve field labels, settings save behavior, expiry filters, alias removal, and privacy descriptions.
- Publish tagged releases to GitHub only by default. Chrome and Edge publication requires a separately authorized manual action.

## Validation

- 685 unit tests and 62 browser tests passed, including popup closure, browser restart, concurrent requests, progress disclosure and expiry, scope/account separation, policy lookup failures, and settings changes during loading.
- Type checking, build, version synchronization, Edge compatibility, dependency audit, and extension packaging passed.
- Five new regression assertions fail against the previous release and pass with these fixes.
- Security review found no confirmed exploitable vulnerability. Request tests use synthetic accounts and offline Microsoft API responses; live tenant mutations were not performed.
- This version is published on GitHub only. Chrome and Edge submissions remain on hold.
