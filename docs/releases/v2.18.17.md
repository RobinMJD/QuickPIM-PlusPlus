Changes since [v2.18.16](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.16).

## Changelog

- Fix **View requests** opening an almost invisible panel when the popup contains a long list of eligible roles. Running requests, completed results, and their original parameters remain readable in the scrollable panel.
- Restore a visible activity bar while requests are pending, including after reopening the popup. It indicates ongoing work without claiming an estimated completion percentage and respects reduced-motion settings.
- Keep role selection, other requests, and the Settings footer usable while request details are expanded. Background execution and safe restart recovery are unchanged.

## Validation

- Browser regressions cover 34 eligible items, running and completed requests, light and dark themes, popup closure, and browser restart.
- 659 unit tests and 33 browser tests passed. Type checking, Edge compatibility, version synchronization, build, package verification, and dependency audit passed.
