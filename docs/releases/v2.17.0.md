Changes since [v2.16.5](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.16.5).

## Changelog

### Browser Sync consistency

- Added validated atomic snapshot generations so partially delivered, corrupt, stale, or unsupported cloud data is never applied.
- Added field-aware reconciliation for preferences, enabled tabs, aliases, favorites, saved reasons, bundles, activity, and per-installation usage counters.
- Preserved concurrent edits from multiple computers without double-counting activity or silently restoring deleted values.
- Delayed generation acknowledgement until cloud read-back, allowing competing last-writer updates to reconcile on the next pass.
- Accounted for the browser sync service's real JSON storage usage and retained complete local categories when a bounded cloud snapshot must be truncated.

### Recovery and data integrity

- Split cloud purge and resume state into independent monotonic markers, rejected stale snapshot epochs, and prevented older installations from recreating purged data.
- Retired stale installation records while preserving active device names and source attribution.
- Coalesced duplicate background synchronization, retried transient sync delivery errors, and kept Settings usable when the browser sync service is temporarily unavailable.
- Canonicalized role identifiers across aliases, favorites, usage, activity, restored selections, and request fingerprints.
- Hardened request recovery, token refresh coordination, partial Azure scope results, timestamps, and bounded imported or synchronized collections.

## Validation

- 467 automated unit and integration tests passed.
- Type checking, production build, eight browser UI checks, Microsoft Edge compatibility, and Edge sideload smoke passed.
- Dependency audit reported zero known vulnerabilities.
- Chrome Web Store and Microsoft Edge Add-ons received the same verified Chromium package.
