Changes since [v2.18.0](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.0).

## Changelog

### Access and activation recovery

- Restores tenant identity on older cached role records and verifies both the Microsoft principal and tenant before privileged writes.
- Requires a genuinely refreshed target token after a portal-access failure, closes stale managed recovery tabs, and preserves the selected roles and activation inputs while recovery runs.
- Separates claims/MFA challenges from ordinary missing-scope recovery, with clearer guidance and bounded foregrounding of the Microsoft prompt when interaction is required.

### Browser Sync reliability

- Batches snapshot chunks and coalesces rapid local or remote changes to stay within Chrome and Edge sync-write budgets.
- Reduces installation heartbeat writes and adds a persisted cooldown with automatic retry when the browser temporarily enforces its write-rate quota.
- Replaces raw quota errors with a friendly status and next-retry time while keeping local data authoritative.
- Keeps the installation-name field focused and editable while its autosave is running.

## Validation

- 522 unit tests across 44 files.
- 8 Playwright browser flows.
- TypeScript, production build, dependency audit, version synchronization, Edge compatibility, and Store-package verification passed.
