Changes since [v2.18.21](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.21).

## Changelog

- Show approved activations as PIM active when Microsoft has exposed the active assignment, even if the request endpoint still reports awaiting approval. Keep the correct countdown and make disabling available again.
- Persist confirmed activation status across popup reopening and background checks. Clear the request-progress notice after the usual completion interval and prevent stale responses from returning it to awaiting approval.
- Keep separate accounts, tenants, scopes, group relationships, older assignments and future extensions isolated during status reconciliation.
- Harden the development glob parser against excessive work from repeated patterns.

## Validation

- 693 unit tests and 64 browser tests passed, including approval delays, background tracking, popup reopening, completion-notice expiry and deactivation availability.
- The new regression reproduces the approval-label/countdown contradiction on v2.18.21 and passes with the fix.
- Type checking, build, Edge compatibility, version synchronization, dependency audit and package verification passed.
- Microsoft request tests use synthetic accounts and offline API responses; no live tenant mutations were performed.
