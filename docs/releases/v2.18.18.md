Changes since [v2.18.17](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.17).

## Changelog

- Keep the main popup focused on unfinished requests and final results that have not yet been viewed.
- Show each completed result once. After viewing it, closing the popup or hiding the panel clears it from the popup; full history remains in Settings > Activity & Usage.
- Preserve unseen results, including completions while the popup was closed. Results below the scroll area are not marked as viewed.
- Keep pending approvals and unresolved outcomes visible, and move the existing completed backlog out of the popup during upgrade.
- Retain background execution, restart recovery, request parameters, and the progress indicator.

- 662 unit tests and 36 browser tests passed. Type checking, version synchronization, Edge compatibility, package verification, build, and dependency audit passed.
