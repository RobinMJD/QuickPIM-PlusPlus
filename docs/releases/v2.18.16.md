Changes since [v2.18.15](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.15).

## Changelog

QuickPIM++ now keeps PIM work separate from the popup form. Activations, deactivations, bundles and access extensions continue in the background after the popup closes. Reopening shows the same saved operations and their actual status.

- Use the compact Requests strip to inspect each item, scope, requested duration, original account/tenant, justification, ticket and Microsoft result.
- Start unrelated requests while earlier work runs. Conflicting work is guarded per account and item/scope, and completing an older request does not overwrite a new form.
- Browser restart restores accepted and uncertain outcomes without replaying writes. Only never-sent items may resume, with usable original-account access within 15 minutes.
- Individual results show approval, scheduling, activation, deactivation, partial failure and unknown outcomes. Estimated activation percentage bars have been removed.
- No new permissions or dependencies.

## Validation

- 659 unit tests and 31 offline Chromium browser tests passed, including popup closure and real browser restart.
- Type checking, Edge compatibility, package validation, and dependency audit passed.
- Tests use synthetic accounts and an offline Microsoft API stub; no tenant privileges were changed.
