Changes since [v2.18.19](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.18.19).

## Changelog

- Keep expanded request details readable in a scrollable dialog, including when another activation form, notices, or larger text fill the popup. Close it with Hide requests or Escape to continue other work.
- Show the progress bar and refresh animation from submission through assignment confirmation, with the current phase on each requested role.
- Clear completed notices automatically after ten seconds, keep expired notices from returning during later refreshes, and retain full history in Activity & Usage.
- Keep approvals, scheduled requests, uncertain outcomes, and unavailable tracking visible until resolved.
- Refresh account context when Microsoft accounts change, avoid refreshes for old completed requests, and keep one completed request from showing a success check while other work continues.
- Preserve background execution, popup closure, browser restart recovery, independent requests, and duplicate-write guards.

## Validation

- 666 unit tests and 51 browser tests passed. Type checking, version synchronization, Edge compatibility, package verification, build, and dependency audit passed.
- Request tests use synthetic accounts and offline Microsoft API responses.
