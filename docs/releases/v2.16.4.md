Changes since [v2.13.14](https://github.com/RobinMJD/QuickPIM-PlusPlus/releases/tag/v2.13.14).

## Changelog

### v2.16.4 - Security audit and hardening

- Completed a repository-wide audit covering token capture, privileged Microsoft requests, extension messaging, browser sync, imports, diagnostics, dependencies, and release automation.
- Removed Microsoft portal URL fragments from token provenance and support reports.
- Made full reset purge synchronized cloud data before deleting local/session data, preventing old sync data from restoring itself later.
- Revalidated token audience, expiry, not-before time, tenant, and principal immediately before privileged writes.
- Rejected API redirects and omitted ambient browser credentials and referrers from Microsoft API requests.
- Added early bounds and unsafe-key rejection for caches, learned names, settings backups, and synchronized data.
- Limited portal token collection to the top frame and retained session-only token storage.

### v2.16.3 - Identity, cache, and recovery reliability

- Prevented inactive Entra tabs from silently changing the captured Microsoft account.
- Bounded and sanitized cached role data while removing unused raw Microsoft response objects.
- Rejected future-dated cache, learned-name, and tracked-request metadata.
- Added clean timeouts for portal IndexedDB token discovery.
- Made active-role date parsing tolerate malformed Microsoft dates without hiding an entire role source.

### v2.16.2 - Concurrent sync and request recovery

- Prevented Browser Sync from overwriting concurrent local preference changes or undoing a local sync-disable action.
- Removed stale cloud chunks and obsolete device records without deleting fresh concurrent updates.
- Coordinated tracked requests, recovery journals, and popup drafts across extension pages.
- Rejected impossible operation timestamps and activation durations.

### v2.16.1 - Stable activation review

- Kept Back, Activate/Disable, Unselect all, and Settings reachable in a fixed action footer.
- Made the activation form independently scrollable during long justifications, request progress, warnings, and errors.
- Prevented popup overflow at the supported compact viewport.

### v2.16.0 - Device identity and cross-device concurrency

- Added persistent installation IDs and user-defined device names for Browser Sync.
- Attributed requests, activity, and usage counters to the originating computer.
- Merged concurrent activity as immutable events and usage through per-installation counters.
- Added stable operation IDs so retries and popup reopening do not double-count work.
- Kept Microsoft authoritative when separate computers submit the same PIM operation simultaneously.

### v2.15.0 - Browser-account sync

- Added default-on synchronization for preferences, aliases, favorites, justifications, bundles, usage counters, and recent activity on official Store installations.
- Kept tokens, API caches, learned names, popup drafts, live requests, and notification permission local-only.
- Added controls to disable sync per installation, force synchronization, rename installations, inspect last-sync times, and purge the cloud copy.
- Preserved Backup & Restore as the path between Chrome Sync and Microsoft Edge Sync, which remain separate services.

### v2.14.0 - Store-aware Edge migration

- Added browser and Store provenance to Diagnostics and sanitized support reports.
- Guided Microsoft Edge users from a Chrome Web Store installation to the native Edge Add-ons edition.
- Added one-click settings/history export before moving an already-used profile.
- Kept development, sideloaded, managed, unknown, and Chrome-native installations usable.

## Validation

- 422 automated unit and integration tests passed.
- Type checking, production build, eight browser UI checks, Microsoft Edge compatibility, and real Edge sideload smoke passed.
- Dependency audit reported zero known vulnerabilities.
- Chrome Web Store and Microsoft Edge Add-ons received the same verified Chromium package.
